class oomph\+::\+Fixed\+Size\+Matrix$<$ T, NROW, NCOL $>$}
Class for fixed-\/size matrix storing NROW x NCOL objects of type T. 

No resize or other STL functionality but therefore much less run-\/time overhead.

Storage is row-\/major\+:

(0,0), (0,1), ..., (0,NCOL-\/1), (1,0), (1,1), ..., (1,NCOL-\/1), ... (NROW-\/1,NCOL-\/1)
