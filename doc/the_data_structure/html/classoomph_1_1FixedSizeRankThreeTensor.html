Detailed Description

template<class T, unsigned N1, unsigned N2, unsigned N3>
class oomph::FixedSizeRankThreeTensor< T, N1, N2, N3 >

Class for fixed-size rank-three tensor storing N1 x N2 x N3 objects of type T.

Storage layout:

(0,0,0), (0,0,1), ... , (0,0,N3-1), (0,1,0), ... ... (N1-1,N2-1,N3-1)
