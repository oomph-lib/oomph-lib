3\mainpage Axisymmetric solid mechanics: a time-dependent demo problem
4
5This example considers the application of the axisymmetric PVD equations introduced in a
6<A HREF="../../axisym_solid/shell/html/index.html">previous tutorial</A> toward a time-dependent problem.
7
8\section description Problem description
9The problem under consideration is a benchmark test using the method of manufactured solutions.
10Similar to the approach used in the previous tutorial, a solution in spherical symmetry is sought.
11The imposed displacment field is:
12\f[
13 u(\hat{r},t) = \hat{R}(\hat{r},t) - \hat{r} = A(t)\hat{r} + \frac{B(t)}{\hat{r}^2},
14\f]
15where the chosen time-dependence for \f$A(t)\f$ and \f$B(t)\f$ are:
16\f[
17 A(t) = A_0\sin(\omega t), \hspace{1cm} B(t) = B_0\sin(\omega t)
18\f]
19Using the same compressible Neo-Hookean constitutive law as previously, the body force required for the manufactured
20solution to be an exact solution is:
21\f[
22 \mathbf{b} = -\left\{\omega^2 u +
23 \mu\left[\frac{\partial \lambda_{\hat{R}}}{\partial \hat{r}} + \frac{2}{\hat{r}}(\lambda_{\hat{R}}-\lambda_{\Theta})\right]
24 + \frac{\lambda}{J\lambda_{\hat{R}}}\frac{\partial J}{\partial \hat{r}}
25 + \left[\frac{1}{\lambda_{\hat{R}}^2}\frac{\partial\lambda_{\hat{R}}}{\partial \hat{r}} +
26 \frac{2}{\hat{r}}\left(\frac{1}{\lambda_{\Theta}}-\frac{1}{\lambda_{\hat{R}}}\right)\right]
27 (\mu-\lambda\log J)\right\}\mathbf{e}_{\hat{r}},
28 \ \ \ \ \ \ \ \ (1)
29\f]
30where \f$\mu = 1/[2(1+\nu)]\f$ and \f$\lambda = \nu/[(1+\nu)(1-2\nu)]\f$ are the dimensionless Lamé parameters (other symbols retain
31their meaning from the <A HREF="../../axisym_solid/shell/html/index.html">previous tutorial</A>).
32The required traction force on the inner and outer faces of the shell is:
33\f[
34 \mathbf{t} = \frac{1}{J}\left[\mu (\lambda_{\hat{R}}^2-1) + \lambda \log J\right]\mathbf{n},
35 \ \ \ \ \ \ \ \ (2)
36\f]
37where \f$\mathbf{n}\f$ is the unit normal.

50\section namespaces Global parameters and functions
51
52The namespace \c GlobalPhysicalVariables contains the material's Poisson ratio and the parameters \f$A_0\f$,
53\f$B_0\f$ and \f$\omega\f$ that parameterise the manufactured displacement solution.
54The functions \c deformed_position_fct, \c deformed_velocity_fct and \c deformed_accel_fct are
55used to set the initial condition. The namespace also contains functions
56\c body_force_fct and \c traction_force_fct which
57define the forcing given by equations (1) and (2), respectively.
58\dontinclude shell_unsteady.cc
59\skipline start_namespace
60\until // namespace GlobalPhysicalVariables
61
62A seperate namespace \c GlobalSimSettings then defines the simulation parameters such as the mesh dimensions,
63the number of timesteps in the run and the flag indicating if the solid pressure formulation is to be used.
64\skipline start_namespace
65\until // namespace GlobalSimSettings

67\section mesh The mesh
68As done in the <A HREF="../../axisym_solid/shell/html/index.html">previous tutorial</A>, the mesh is constructed
69by upgrading the existing \c TwoDAnnularMesh to a solid mesh.
70\skipline start_mesh
71\until };

73\section problem_class The problem class
74The problem class is relatively standard and is identical to the previous tutorial, execpt for the addition of
75the member functions \c set_initial_condition(), which sets the initial condition manually using functions
76provided in \c GlobalPhysicalVariables, and \c unsteady_run() which performs the time integration.
77\skipline start_problem
78\until };

80\section constructor The problem constructor
81The constructor begins with assigning the output directory and setting \c Newmark<1> as the problem's
82timestepper. Following this, the bulk and surface meshes are created and the member function \c create_boundary_elements()
83is called to create traction elements on the outer boundary of the shell. \c complete_problem_setup() (discussed below) is
84called to complete the setup of the bulk and surface elements and assign Dirichlet boundary conditions. \c set_initial_condition()
85(also discussed below) is called to manually set an initial condition which is consistent with the manufactured solution.
86\skipline start_constructor
87\until // end constructor
88
89\section complete Completing the problem setup
90To complete the problem setup, the pointers for the constutive law and body force function are passed to each
91of the bulk elements. The pointer to the traction force is then passed to each of the interface elements. Finally,
92the Dirichlet boundary conditions for the problem are set.
93\skipline start_of_complete_problem_setup
94\until // end complete_problem_setup
95
96\section initial_condition Setting the initial condition
97Since this tutorial uses a manufactured solution, the nodal positions, velocities and accelerations are known at all times
98and so the initial condition can be set manually. The \c Newmark<1> timestepper stores the following values:
99 - 0: Displacement at time \f$ t \f$.
100 - 1: Displacement at time \f$ t-dt \f$.
101 - 2: Velocity at time \f$ t-dt \f$.
102 - 3: Acceleration at time \f$ t-dt \f$.
103
104These values are easily accessible using the functions \c deformed_position_fct, \c deformed_velocity_fct and
105\c deformed_accel_fct in the namespace \c GlobalPhysicalVariables.
106\skipline start_of_set_initial_condition
107\until // end set_initial_condition

109\section driver The driver code
110The driver code is relatively simple. Command line arguments for the material's Poisson ratio and the \c use_solid_pressure
111flag are specified. Following this, the problem is built and solved by calling the member function \c unsteady_run,
112which simply perfoms the Newton solve and output within a timestepping loop.
113\skipline start_main
114\until // end main
