\chapter{Axisymmetric solid mechanics\+: a time-\/dependent demo problem}
\hypertarget{index}{}\label{index}\index{Axisymmetric solid mechanics: a time-\/dependent demo problem@{Axisymmetric solid mechanics: a time-\/dependent demo problem}}
This example considers the application of the axisymmetric PVD equations introduced in a \href{../../axisym_solid/shell/html/index.html}{\texttt{ previous tutorial}} toward a time-\/dependent problem.\hypertarget{index_description}{}\doxysection{\texorpdfstring{Problem description}{Problem description}}\label{index_description}
The problem under consideration is a benchmark test using the method of manufactured solutions. Similar to the approach used in the previous tutorial, a solution in spherical symmetry is sought. The imposed displacment field is\+:  \[
  u(\hat{r},t) = \hat{R}(\hat{r},t) - \hat{r} = A(t)\hat{r} + \frac{B(t)}{\hat{r}^2},
\] where the chosen time-\/dependence for $A(t)$ and $B(t)$ are\+:  \[
  A(t) = A_0\sin(\omega t), \hspace{1cm} B(t) = B_0\sin(\omega t)
\] Using the same compressible Neo-\/\+Hookean constitutive law as previously, the body force required for the manufactured solution to be an exact solution is\+:  \[
  \mathbf{b} = -\left\{\omega^2 u +
  \mu\left[\frac{\partial \lambda_{\hat{R}}}{\partial \hat{r}} + \frac{2}{\hat{r}}(\lambda_{\hat{R}}-\lambda_{\Theta})\right]
  + \frac{\lambda}{J\lambda_{\hat{R}}}\frac{\partial J}{\partial \hat{r}}
  + \left[\frac{1}{\lambda_{\hat{R}}^2}\frac{\partial\lambda_{\hat{R}}}{\partial \hat{r}} + 
  \frac{2}{\hat{r}}\left(\frac{1}{\lambda_{\Theta}}-\frac{1}{\lambda_{\hat{R}}}\right)\right]
  (\mu-\lambda\log J)\right\}\mathbf{e}_{\hat{r}},
  \ \ \ \ \ \ \ \ (1)
\] where $\mu = 1/[2(1+\nu)]$ and $\lambda = \nu/[(1+\nu)(1-2\nu)]$ are the dimensionless Lamé parameters (other symbols retain their meaning from the \href{../../axisym_solid/shell/html/index.html}{\texttt{ previous tutorial}}). The required traction force on the inner and outer faces of the shell is\+:  \[
  \mathbf{t} = \frac{1}{J}\left[\mu (\lambda_{\hat{R}}^2-1) + \lambda \log J\right]\mathbf{n},
  \ \ \ \ \ \ \ \ (2)
\] where $\mathbf{n}$ is the unit normal.\hypertarget{index_results}{}\doxysection{\texorpdfstring{Results}{Results}}\label{index_results}

The namespace {\ttfamily \doxylink{namespaceGlobalPhysicalVariables}{Global\+Physical\+Variables}} contains the material\textquotesingle{}s Poisson ratio and the parameters $A_0$, $B_0$ and $\omega$ that parameterise the manufactured displacement solution. The functions {\ttfamily deformed\+\_\+position\+\_\+fct}, {\ttfamily deformed\+\_\+velocity\+\_\+fct} and {\ttfamily deformed\+\_\+accel\+\_\+fct} are used to set the initial condition. The namespace also contains functions {\ttfamily body\+\_\+force\+\_\+fct} and {\ttfamily traction\+\_\+force\+\_\+fct} which define the forcing given by equations (1) and (2), respectively.

 \hypertarget{index_constructor}{}\doxysection{\texorpdfstring{The problem constructor}{The problem constructor}}\label{index_constructor}
The constructor begins with assigning the output directory and setting {\ttfamily Newmark$<$1$>$} as the problem\textquotesingle{}s timestepper. Following this, the bulk and surface meshes are created and the member function {\ttfamily create\+\_\+boundary\+\_\+elements()} is called to create traction elements on the outer boundary of the shell. {\ttfamily complete\+\_\+problem\+\_\+setup()} (discussed below) is called to complete the setup of the bulk and surface elements and assign Dirichlet boundary conditions. {\ttfamily set\+\_\+initial\+\_\+condition()} (also discussed below) is called to manually set an initial condition which is consistent with the manufactured solution.

 \hypertarget{index_initial_condition}{}\doxysection{\texorpdfstring{Setting the initial condition}{Setting the initial condition}}\label{index_initial_condition}

\item 0\+: Displacement at time $ t $.
\item 1\+: Displacement at time $ t-dt $.
\item 2\+: Velocity at time $ t-dt $.
\item 3\+: Acceleration at time $ t-dt $.
\end{DoxyItemize}
